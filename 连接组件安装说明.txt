Orca Queue Connection 0.7.3 · Windows x64

本包是独立连接安装工具，不是 Orca 市场插件。仅在首次安装或连接桥接需要更新时运行。

1. 先结束或核对打印任务，保存工程，完整退出 OrcaSlicer。
2. 把整个 ZIP 解压到普通文件夹，不要直接在压缩包里运行独立安装工具。
3. 点击“检查”。检查不会创建或修改 Orca 文件。
4. 点击“安装 / 更新”，核对显示的目标目录并确认。无需管理员权限，无需 Python 或 PowerShell。
5. 重新打开 Orca，在首页登录 Bambu Cloud。队列的更新状态中应显示状态历史与完整 AMS 映射已启用。

安装目标默认是当前用户的 OrcaSlicer 数据目录下 plugins。便携版可点“选择 Orca 数据目录”，选择实际数据目录。安装器不修改 orca_plugins、账号、队列或配置。
运行独立安装工具会实际替换联网文件；请先阅读可见源码。若 Windows 安全策略阻止此工具，请由本机管理员审核处理；本项目不自动解除安全限制。

备份与恢复
原文件备份在 Orca 数据目录 queue-connection-backups 下，每次操作有 receipt.json。已有匹配组件时不重复写入或覆盖最近备份。
需要恢复时先关闭 Orca，再打开独立工具并点“恢复原组件”。恢复前会核对当前文件和备份。被其他程序更新的文件不会覆盖；不要删除备份目录。
不认识的联网组件或接口会拒绝覆盖，不要自行重命名 DLL。已有 live555.dll 和 BambuSource.dll 会保留。

完整对应源码：本包 source-0.7.3.zip。联网 DLL 来自 Open Bamboo b14f880 及本项目队列桥接；原始 NOTICE 和许可已随包提供。本包与拓竹、OrcaSlicer 官方无隶属关系。

独立工具尚未进行商业代码签名，Windows 可能显示未知发布者。请核对可信来源与 SHA256；若被安全策略阻止，不要关闭防护。工具提供可阅读源码和完整对应源码包。
