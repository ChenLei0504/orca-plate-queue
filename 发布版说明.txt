长路径复查 / Long-path follow-up

0.7.12 继续缩短新增打印机数据库、上传暂存、语言设置临时文件和模型/换盘缓存路径。完整文件哈希校验和打印机隔离保持启用。
已有数据库与任务路径不搬动；过深的宿主目录、旧长路径和 Orca 的权限/卸载行为仍可能需要处理。适配器仍为 0.7.5，无需重装。实际 Orca 弹窗待安装后核对。
Shorter new database, upload, preference and cache paths; full hash checks and printer isolation remain. Existing databases/task paths are retained. Deep host roots, legacy paths and host audit/uninstall behavior remain limitations. Keep adapter 0.7.5. Actual Orca prompts require verification after installation.

导入缓存权限修复 / Import cache permission fix

0.7.11 缩短云端安装后多打印机的新缓存路径，减少因 Windows 长路径前缀导致的逐个临时文件授权。
旧队列数据库和已有任务路径保持不变；新缓存仍在插件私有存储内，按打印机隔离，并校验所属队列。
没有关闭 Orca 权限审核，也没有请求整盘或用户目录权限。用户选择的外部文件仍按 Orca 规则授权。
已按报告中的目录长度验证连续导入、旧任务重载和缓存隔离。真实 Orca 弹窗行为待安装后核对。
请等当前打印结束后再更新队列插件。连接适配器继续使用 0.7.5。

0.7.11 shortens new per-printer cache paths under plugin-private storage to avoid per-file prompts caused by extended Windows paths in cloud installs. Existing task paths are preserved; cache ownership and printer isolation are checked. Orca audit enforcement and external-file authorization remain in place. Actual prompt behavior requires verification in Orca after installation.

设备状态修复 / Printer status fix

0.7.10 修复已建立队列但没有活动任务时，将实际打印中的设备显示为“空闲”的问题。
左侧打印机卡片与右侧状态统一使用设备实时回报；队列等待换板、核对等提示单独显示。
状态过期显示“等待回报”，未知状态不判断为空闲；非本队列启动的打印显示实际状态和进度，不自动接管。
本次仅更新队列插件，连接适配器继续使用 0.7.5。当前正在打印时，请等待打印结束后再安装或重启 Orca。

0.7.10 fixes an existing but inactive queue incorrectly showing a busy printer as idle.
Fleet and device panels now use fresh printer telemetry; queue notices remain separate. Stale reports show Waiting for status. External tasks display status and progress without being adopted or controlled.
Only the queue wheel needs updating; keep adapter 0.7.5. Wait until the current print finishes before installing or restarting Orca.

Open Bamboo 0.2.45 compatibility remains unchanged.

0.7.9 基于 0.7.8 的队列桥接方案，新增 Open Bamboo 0.2.45 兼容适配包。连接适配器 0.7.5 保留用户已安装的兼容 Open Bamboo 核心，继续复用 Orca 首页的 Bambu Cloud 登录；不需要独立云登录。

安装：
1. 在 Open Bamboo 页面安装 / 更新联网库。插件列表版本更新不等于核心已更新。
2. 保存工程并完整退出 Orca。
3. 完整解压 Orca-Queue-Connection-0.7.5-Windows-x64.zip，打开 OrcaQueueConnectionSetup.exe，检查后安装 / 重新适配。
4. 启动 Orca，安装或启用本包 0.7.12 队列 wheel。页面构建应为 20261103.12。
5. 继续使用 Orca 首页 Bambu Cloud 登录，核对打印机温度及 AMS 后再由用户开始测试打印。

Open Bamboo 将来更新可能覆盖桥接入口；届时退出 Orca 后重新适配。适配器不常驻，不自动更换联网库，不改动账号和队列。

已验证：0.2.45 源码 32e31a3 的公开 ABI 头文件、导出函数签名；四个入口的虚拟 SDK 测试；实际 DLL 副本的安装、保留和恢复。
尚未验证：本次新版核心下的真实打印、AMS 进料、打印完成后换盘、Handy 同时在线。
本包为本地验证产物，尚未推送 GitHub 或发布云市场。

保留 0.7.8 既有任务功能：A1 / P1S 独立队列、模型预览、耗材与份数配置、拖拽排序、任务删除、零件跳过、中断核对、中文 / English。
A1 自动换盘需要自行配备兼容机构和换盘文件；P1S 手动清板后确认继续。电脑与 Orca 必须保持运行。
